FFA Toolkit method manual

Use the installed command to fit an explicitly configured model to annual maximum discharges. Review stationarity, independence, record completeness, gauging and rating quality, and the fit's physical support before using results in design. Native Flike qualification and engineering adoption remain separate from the independent calculations described here.

Inputs · Methods · Worked examples · Reading a report · References and further guidance

Prepare the analysis

  1. Supply a UTF-8 CSV with the exact header Year,AMS and one finite positive maximum per year. Record the annual-period definition and a consistent discharge unit in settings. Frequency plots require consecutive years. Missing, censored, historical, zero and rating-error observations require separate analysis methods and explicit exposure.
  2. Choose the settings schema, estimator and all required method fields. Provide strictly increasing non-exceedance probabilities F in (0, 1). For an annual maximum, F=0.99 corresponds to AEP=0.01, a 1% chance of exceeding that model quantile in a year under the model assumptions.
  3. Run ffa fit --ams INPUT.csv --settings SETTINGS.json --output NEW_FOLDER --frequency-report. Use an existing, user-controlled parent for the new output folder.

Choose a deterministic fit

MethodConfiguration and interpretation
Fixed-H GEVUse ffa-gev-fixed-h/1 and gev_lh_fixed_h. Set lh_shift to 0 for ordinary L-moments or 1 to 4 to emphasise larger observations. Higher H needs more data. H is supplied explicitly. The reported shape is ARR/Hosking k, with finite endpoint u + alpha/k for k unequal to zero. Positive k has an upper endpoint and negative k a lower endpoint.
GumbelUse ffa-ordinary-lmoments/1 and gumbel_lmoments. Raw-discharge L1 and L2 determine location and positive scale. The model can yield negative mathematical quantiles at common probabilities.
Two-parameter lognormalUse the ordinary schema and lognormal_lmoments. Supply positive reference_discharge in the source unit. Raw L1 and L2 determine the parameters. The report states mean of ln(Q/reference) and the natural log of that log-discharge standard deviation.
Log-Pearson IIIUse the ordinary schema and lp3_lmoments. Supply positive reference_discharge. The first three L-moments of ln(Q/reference) fit its mean, standard deviation and signed skew. The reported spread coordinate is ln(SD). At zero skew the log-coordinate fit has its normal limit.
Generalized ParetoUse the ordinary schema and gp_lmoments. Set gp_location_mode to fixed with explicit gp_location to fit two raw L-moments, or free to fit three. Reported EVT shape xi is the negative of ARR/Hosking kappa. These settings model the annual maxima supplied. They do not estimate a peaks-over-threshold arrival rate.

Run all ten synthetic configurations

Save the following as run_examples.py and run python run_examples.py in an environment with the installed wheel. Each run creates a fresh directory with its settings, inputs and ten report bundles. The source samples are synthetic.

import json
import subprocess
import sys
import tempfile
from importlib.resources import files
from pathlib import Path

resources = files("ffa_methods").joinpath("resources", "examples")
root = Path(tempfile.mkdtemp(prefix="ffa-examples-", dir=Path.cwd()))
for prefix in ("fixed-gev", "ordinary"):
    filename = f"{prefix}-ams.csv"
    (root / filename).write_bytes(resources.joinpath(filename).read_bytes())

def run(name, prefix, **changes):
    settings = json.loads(resources.joinpath(f"{prefix}-settings.json").read_bytes())
    settings.update(changes)
    config = root / f"{name}.json"
    config.write_text(json.dumps(settings), encoding="utf-8")
    subprocess.run(
        [sys.executable, "-m", "ffa_methods", "fit", "--ams", f"{prefix}-ams.csv",
         "--settings", config.name, "--output", name, "--frequency-report"],
        cwd=root, check=True,
    )

for h in range(5):
    run(f"gev-h{h}", "fixed-gev", lh_shift=h)
run("gumbel", "ordinary")
run("ln2", "ordinary", estimator="lognormal_lmoments", reference_discharge=2)
run("lp3", "ordinary", estimator="lp3_lmoments", reference_discharge=2)
run("gp-fixed", "ordinary", estimator="gp_lmoments", gp_location_mode="fixed", gp_location=0.25)
run("gp-free", "ordinary", estimator="gp_lmoments", gp_location_mode="free")
print(root)

For the three ordinary discharges (1, 2, 4), raw L1=7/3 and L2=1. Descending Cunnane positions are 3/16, 1/2 and 13/16. The free-location GP median is 1/3 + 2 ln(2). For each GEV example, check a reported quantile from Q(F)=u+alpha/k [1-(-ln F)k] or its limit u-alpha ln(-ln F) at k=0. Compare each result at the requested probability against its plotted marker and table row.

Exact-record Bayesian worked example

Use the same installed wheel and a fresh working directory. Copy the original synthetic fixed-scale input and settings using the bundled resources. This example's quantile precision is unassessed; the separate expected-AEP audit is not a quantile uncertainty guarantee.

import subprocess
import sys
import tempfile
from importlib.resources import files
from pathlib import Path

root = Path(tempfile.mkdtemp(prefix="ffa-bayesian-", dir=Path.cwd()))
resources = files("ffa_methods").joinpath("resources", "examples")
for name in ("bayesian-fixed-ams.csv", "bayesian-fixed-settings.json"):
    (root / name).write_bytes(resources.joinpath(name).read_bytes())
subprocess.run(
    [sys.executable, "-m", "ffa_methods", "fit", "--ams", "bayesian-fixed-ams.csv",
     "--settings", "bayesian-fixed-settings.json", "--output", "report", "--frequency-report"],
    cwd=root, check=True,
)
print(root)

Read the pointwise limits and numerical precision states as separate information. Probability-at-flow results remain in the numerical report. The exact Year,AMS plot does not rank censored, historical or gapped records.

Read the report

  • Observe the dark Cunnane markers and hollow fitted markers. The horizontal axis is log AEP with values shown in percent. The numeric tables show probability fractions. The vertical axis is linear in the declared discharge unit. The ordinate can include signed model quantiles.
  • Check the requested fitted quantiles and warnings first. Segments connect requested outputs as visual guides. Cunnane AEP=(rank-0.4)/(n+0.2) uses the greatest observation as rank 1. Ties are displayed in ascending year order. These dependent rank positions are empirical diagnostics. Use the fitted distribution to estimate event probability.
  • Review the detailed fitted-support diagnostics, including GEV observations outside the support and observations exactly at the endpoint. Negative mathematical quantiles are retained and flagged. These warnings can affect whether a fit is suitable for design.
  • These reports have deterministic point estimates. A quantile at expected parameters, posterior mean or median of quantiles, and quantile of the predictive mixture have distinct meanings. A pointwise posterior quantile interval describes parameter-induced uncertainty at one F. Its width is distinct from a predictive interval, a simultaneous band, or Monte Carlo error. The exact Year,AMS Bayesian plot displays the separate central estimands and requested pointwise posterior quantile limits. Censored/historical and bootstrap plots remain unavailable.
  • Retain results.json, results.csv, report.txt, frequency-coordinates.csv and both source snapshots. Source and settings hashes identify the analysed bytes. Replay with the same package and dependency versions using the command in the report. Consult the SVG or printable HTML without a network connection.

References and further guidance

Use ffa references ARR3 for ARR 2019 Book 3 v4.2, sections 2.6.2 and 2.6.4, and ffa references CUNNANE1978 for the plotting-position reference. Use ffa explain l-moments --format markdown, ffa explain lh-moments-gev --format markdown and ffa explain frequency-plots --format markdown for the full estimator identities, boundary cases and validation limits. ffa explain lists broader mathematical components and their status. Registered components may have no installed fitting path.
