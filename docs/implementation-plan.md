# Implementation plan

The accepted baseline retains kernels, fixed-H/ordinary estimators, likelihood/prior/rating and low-flow
components, real importance execution, weighted outputs, typed reports and a fixed-H installed CLI.
Remaining public software work is owned by the mapped Toolkit issues: model bindings, covariance
scaling, output precision, ordinary/Bayesian installed workflows, exposure/rating integration, standardized
LH diagnostics/optimized H, external comparisons and scientific reports/plots/examples. Migrate pending
work through focused reviewed PRs and preserve all incomplete acceptance criteria. No native-equivalence
or release claim follows from initial software completion.

See the [supported-calculation planning](https://github.com/Chain-Frost/ffa-toolkit/issues/14), [development requirements](development.md)
and [agent instructions](../AGENTS.md).
