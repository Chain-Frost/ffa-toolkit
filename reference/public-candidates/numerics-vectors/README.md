# Independent mathematical vectors

Retained vectors cover generated modular samples with exact Fraction L-moments, the analytic
LP3-to-uniform identity, Normal tail-interval probabilities and an analytic Normal posterior.
JSON files preserve calculation definitions, source pins, numerical precision and tolerances.
The inspected Numerics source is 0BSD; no implementation code is copied.
The third-party textbook observation sample and derived GEV fit vectors are excluded because
underlying observation redistribution rights are unresolved.
See [notices](../../../THIRD_PARTY_NOTICES.md). No vector establishes native Flike qualification.
