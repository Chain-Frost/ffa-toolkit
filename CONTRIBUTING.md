# Contributing

Read [AGENTS.md](AGENTS.md), the [development requirements](docs/development.md) and relevant method
specifications. Use focused PRs, independent numerical evidence and the complete applicable quality
contract. State validation actually run and remaining limits. Preserve the Sustainable Use License 1.0
and applicable third-party notices. Submit only original code and material with established reuse rights.
Do not attach private/native evidence, secrets or local identifying paths to public issues or PRs.
